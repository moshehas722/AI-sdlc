# HarnessStructure

Agentic SDLC harness for Cursor — persona-bound skills, project context, and slash-command workflows. Configuration- and documentation-centric; no application runtime at present.

**For full project context, see [.context/TOC.md](.context/TOC.md).**

Agent behavior for personas and context is defined in `.harness/rules/` and loaded via `.cursor/rules/harness.mdc`.
